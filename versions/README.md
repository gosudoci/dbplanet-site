# DB PLANET 메인 페이지 버전

비교 페이지: 서버를 켠 뒤 http://localhost:8765/versions/ 를 연다.
(`cd ~/dbplanet-site && python3 -m http.server 8765`)

| 버전 | 폴더 | 내용 |
|---|---|---|
| v1 원본 옮김 | `v1/` | Claude Design「메인 페이지」를 HTML·CSS·JS로 변환. 화면은 원본과 같음 |
| v2 디자인 개선 | `v2/` | design-taste-frontend 스킬 적용. 장식 제거, 글씨 6단계, 카테고리 사진 섹션, 하단 재구성 |
| v3 인트로 리뉴얼 | `v3/` | 헤드라인 "브랜드가 보이는 순간", 레퍼런스 영상 3개 반영한 인트로, Magnific 행성 텍스처 |
| v4 마지막 두 섹션 | `v4/` | blink.capital 참고: 메시지로 도착하는 후기, 옆으로 넘어가는 6개월 스토리 카드, 떠오르는 행성 지평선, 진단 리포트 미리보기 |
| v5 6개월 리포트 | `v5/` | v4에서 스토리 카드를 성과 대시보드와 같은 밝은 리포트 카드(월별 순위·막대·한 일)로 교체 |
| v6 6개월 섹션 뺌 | `v6/` | v5에서 "이 브랜드와 함께한 6개월" 섹션 제거, 고객 메시지에서 무료 진단 신청으로 바로 이어짐 |
| v7 브랜드 행성을 달로 | `v7/` | DB / Planets 장면의 우리 행성을 달 표면으로, 문제→이름·이름→서비스 카메라 전환을 길고 부드럽게 |
| v8 달 밝기 자연스럽게 | `v8/` | 서비스 단계에서 하얗게 날아가던 달을 실제 사진 같은 회색으로 (반사·단계별 밝기·명암 경계 조정) |
| v9 큰 제목 빛 채움 | `v9/` | 첫 화면·3D 장면 큰 제목에 일식 빛이 왼쪽부터 채워지는 모션 (스크롤로 나타날 때 + 데스크톱 호버) |
| v10 카테고리 섹션 뺌 | `v10/` | "뷰티·헬스케어 브랜드를 위한 팀입니다" 제거, 인트로 끝 남색 페이드 제거로 빈 화면 없이 성과 데이터로 이어짐 |
| v11 사례 결과물 예시 | `v11/` | 작업 사례 패널 3개에 Magnific 예시: 상세페이지 시안, 세럼 광고 이미지, 5초 숏폼 영상 |
| v12 평평한 사례 패널 | `v12/` | 곡면처럼 휘어 있던 작업 사례 휴대폰 화면 패널을 평면으로 |
| v13 호버 채움 · 후기·신청 정리 | `v13/` | 제목·메뉴 빛 채움을 호버 전용으로, 후기를 큰 인용문 + 스크롤 단어 채움으로, 무료 진단에서 리포트 미리보기 삭제·밑줄형 폼 |
| v14 도는 일식 빛 | `v14/` | 첫 화면 일식 둘레 빛이 일정하게 원을 따라 돎, 원에 마우스를 올리면 빨라지고 스크롤 양만큼 앞뒤로 돎, 돌던 경계선·빗금 제거 |
| v15 후기 바탕 구분 | `v15/` | 고객 후기 바탕을 한 톤 밝은 남색으로 해 무료 진단과 경계를 만듦, 후기의 성과 숫자 3개 삭제 |
| v16 파랑 호버 채움 | `v16/` | 제목·메뉴 호버 채움 색을 일식 빛에서 파랑 그라데이션으로 |
| v17 은색 광택 호버 | `v17/` | 호버하면 흰 제목·메뉴 위로 은회색 광택 띠가 지나감 |
| v18 은색 글자 · 흰빛 스침 | `v18/` | 평소 제목·메뉴는 은회색, 호버하면 흰빛 띠가 스쳐 지나감 (v17 띠가 그림자처럼 보여서) |
| v19 브랜드 스토리 천천히 | `v19/` | DB / Planets 브랜드 스토리 구간 스크롤 길이를 약 1.5배로 늘려 천천히 넘어가게 (요청을 잘못 짚음, v20에서 되돌림) |
| v20 서비스 제목 오래 | `v20/` | "다섯 단계로 함께합니다" 제목 화면이 약 3배 오래 머묾, 브랜드 스토리 길이는 원래대로 |
| v21 스크롤·호버 흰빛 (현재) | `v21/` | 큰 제목의 흰빛 스침이 스크롤로 나타날 때와 호버할 때 모두 (메뉴는 호버만) |
| v22 Magnific 코로나 영상 (되돌림) | `v22/` | 첫 화면 일식 빛을 Magnific 영상(원 둘레를 도는 빛)으로, 호버하면 빨라지고 스크롤로 앞뒤로 돎 |

- 각 버전 폴더의 `assets`는 상위 `../assets`를 가리키는 링크라 이미지는 한 벌만 있다.
- 사이트 루트(`~/dbplanet-site/index.html`)는 v21과 같다 (v22를 본 뒤 되돌림).
- `shots/`는 비교 페이지용 스크린샷(1440×900).
- 버전별 상세 변경 내용과 출시 전 할 일: `../CHANGELOG.md`
